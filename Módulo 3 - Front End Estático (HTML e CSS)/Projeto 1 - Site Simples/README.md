# 🌐 Projeto 1 - Site Simples

## 🎯 Objetivo

Desenvolver um site simples com **três páginas** usando HTML e CSS, aplicando boas práticas de codificação e semântica.

---

## 📄 Estrutura do Projeto

| Página | Arquivo | Descrição |
|--------|---------|-----------|
| 🏠 **Tela Inicial** | `index.html` | Página principal do site |
| ℹ️ **Sobre** | `sobre.html` | Informações sobre o site/empresa |
| ✉️ **Contato** | `contato.html` | Formulário ou informações de contato |

---

## ⚙️ Requisitos

- Arquivos externos de **CSS** organizados separadamente
- Pode utilizar **Bootstrap** ou qualquer outro framework/lib de estilos
- **Boas práticas** de codificação e semântica
- Nomes significativos para **classes**, **IDs** e **comentários explicativos**
- Navegação funcionando entre as três páginas
- Para imagens de placeholder: [placehold.co](https://placehold.co/)

---

## 🚀 Extras (opcionais)

Funcionalidades ou detalhes adicionais a critério do desenvolvedor para melhorar a qualidade do site.
