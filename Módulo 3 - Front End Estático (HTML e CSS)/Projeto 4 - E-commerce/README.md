# 📄 Atividade - Módulo de Front-End Estático

## 🎯 Objetivo

Desenvolver uma página web utilizando **HTML & CSS** ou **Bootstrap 5**, aplicando estrutura semântica, responsividade e navegação entre páginas.

---

## 📰 Opção 1 — Site de Notícias

### Estrutura do Projeto (3 páginas)

| Página | Conteúdo |
|--------|----------|
| 🏠 **Home** | Lista de notícias com imagens, títulos, resumos e links para as páginas internas |
| 📰 **Notícia 1** | Conteúdo completo da notícia com imagens e texto detalhado |
| 📰 **Notícia 2** | Conteúdo completo da notícia com imagens e texto detalhado |

**Referências:** [TecMundo](https://www.tecmundo.com.br/) · [ge.globo](https://ge.globo.com/)

---

## 🛒 Opção 2 — E-commerce

### Estrutura do Projeto (3 páginas)

| Página | Conteúdo |
|--------|----------|
| 🏠 **Loja** | Lista de produtos com imagens, nome, preço e botão de compra/detalhes |
| 🛍️ **Produto 1** | Descrição completa, imagens, preço e formulário (compra ou contato) |
| 🛍️ **Produto 2** | Descrição completa, imagens, preço e formulário |

**Referências:** [Mercado Livre](https://www.mercadolivre.com.br/) · [Kabum](https://www.kabum.com.br/)

---

## ⚙️ Requisitos Obrigatórios

- [x] Site **responsivo**
- [x] **HTML semântico**: `<header>`, `<nav>`, `<main>`, `<article>`, `<footer>`
- [x] **Navegação** funcionando entre as páginas
- [x] Uso de **imagens**
- [x] Inclusão de **formulário** (newsletter, comentário, busca, compra ou contato)
