### Projeto 4 — Atividade Front-End Estático (em grupo)

Desenvolvimento de uma página web utilizando **HTML & CSS** ou **Bootstrap 5**, aplicando estrutura semântica, responsividade e navegação entre páginas.

**Opções do projeto:**

| Opção | Tema | Páginas |
|-------|------|---------|
| Opção 1 | Site de Notícias | Home, Notícia 1, Notícia 2 |
| Opção 2 | E-commerce | Loja, Produto 1, Produto 2 |

**Requisitos obrigatórios:**

- Site responsivo
- HTML semântico (`<header>`, `<nav>`, `<main>`, `<article>`, `<footer>`)
- Navegação funcionando entre as páginas
- Uso de imagens
- Inclusão de formulário
- **Bônus:** Publicar no GitHub Pages

**Minha contribuição:** Desenvolvimento da **Página de Produto 2** (descrição completa, imagens, preço e formulário).
