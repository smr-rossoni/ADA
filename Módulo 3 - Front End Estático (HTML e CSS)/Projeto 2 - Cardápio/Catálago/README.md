# 📋 Projeto 2 — Cardápio/Catálogo Digital

## 🎯 Objetivo

Desenvolver um cardápio ou catálogo digital com HTML e CSS, contendo produtos com imagens, navegação, tabela de preços e formulário de cadastro.

---

## ⚙️ Requisitos

- [x] **Título e descrição** explicando do que se trata o catálogo
- [x] Cada produto deve possuir **imagem**, **nome** e **descrição**
- [x] **Header e footer** com navegação funcional
- [x] **Tabela de preços** (ou com outra função relevante)
- [x] **Formulário** para cadastro

---

## 🚀 Extras

- [x] Página otimizada para **SEO** e **acessibilidade**
- [x] Página com **estilização** (CSS customizado ou framework)
