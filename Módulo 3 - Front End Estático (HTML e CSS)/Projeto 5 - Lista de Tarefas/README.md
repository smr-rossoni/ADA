# 📋 Projeto 5 - Sistema de Controle de Tarefas (To-Do List)

## 📌 Descrição do Projeto

Este projeto consiste em um sistema de gerenciamento de tarefas (To-Do List), onde é possível:

- Criar usuários  
- Gerenciar múltiplas listas de tarefas por usuário  
- Controlar tarefas dentro de cada lista  

> ⚠️ **Importante:**  
> Nesta etapa do projeto, os dados são **mockados**, ou seja, estão fixos no HTML.  
> A manipulação dinâmica será implementada apenas no próximo módulo.

---

## 🎯 Funcionalidades

### 👤 Usuários
- Criar um novo usuário

### 📂 Listas de Tarefas
- Criar uma nova lista  
- Remover uma lista  
- Listar todas as listas de um usuário  

### ✅ Tarefas
- Adicionar tarefa a uma lista  
- Listar tarefas de uma lista  
- Marcar tarefa como concluída  
- Remover tarefa
