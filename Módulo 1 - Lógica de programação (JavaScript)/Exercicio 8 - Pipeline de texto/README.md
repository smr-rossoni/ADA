# 📊 Exercício 8 — Pipeline de Texto

## 📌 Descrição

Construir um pipeline de transformações sobre strings, aplicando funções de limpeza, formatação e análise de texto.

## 🎯 Requisitos

* Criar uma função para remover espaços extras (`trim`)
* Criar uma função para capitalizar a primeira letra de cada palavra
* Criar uma função para remover exclamações (`!`)
* Compor as funções em sequência
* Reescrever as funções como arrow functions de uma linha
* Criar uma função para contar palavras
* Aplicar um pipeline de funções utilizando `reduce`
