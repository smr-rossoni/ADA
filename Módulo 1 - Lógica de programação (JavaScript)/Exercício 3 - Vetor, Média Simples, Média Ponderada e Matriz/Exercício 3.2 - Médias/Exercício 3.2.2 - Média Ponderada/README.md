# 📊 Exercício 3.2.2 — Média Ponderada 

## 📌 Descrição

Calcular a média ponderada de 3 notas utilizando um laço de repetição e pesos.

## 🎯 Requisitos

* Utilizar 3 notas e 3 pesos
* Aplicar um laço para calcular a soma ponderada
* Calcular a média ponderada
* Exibir o resultado no console
