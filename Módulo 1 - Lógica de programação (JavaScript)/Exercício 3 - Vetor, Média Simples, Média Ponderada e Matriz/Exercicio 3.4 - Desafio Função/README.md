# 📊 Desafio — Função de Média

## 📌 Descrição

Criar uma função que receba um array de notas e retorne a média simples.

## 🎯 Requisitos

* Criar uma função `media` que receba um array de números
* Utilizar um laço para somar os valores
* Calcular a média simples
* Retornar o resultado
* Exibir a média formatada no console
