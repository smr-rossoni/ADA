# 📊 Exercício 3 — Matriz 3x3

## 📌 Descrição

Trabalhar com uma matriz 3x3, acessando e alterando o elemento central.

## 🎯 Requisitos

* Criar uma matriz 3x3
* Exibir a matriz completa
* Acessar o elemento central
* Solicitar um novo valor ao usuário
* Atualizar o elemento central
* Exibir a matriz atualizada
