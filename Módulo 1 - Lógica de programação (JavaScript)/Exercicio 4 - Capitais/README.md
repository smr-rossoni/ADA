# 📊 Exercício 4 — Map (País → Capital)

## 📌 Descrição

Criar um dicionário de capitais utilizando `Map`, permitindo busca por país e listagem das capitais em ordem alfabética.

## 🎯 Requisitos

* Criar um `Map` com pares (país → capital)
* Implementar uma função de busca da capital pelo nome do país
* Criar uma função que liste as capitais em ordem alfabética
* Criar uma função que retorne todos os dados
