# 📊 Exercício 7 — Inventário

## 📌 Descrição

Percorrer um array de objetos e um dicionário de preços, realizando operações de listagem, cálculo e filtragem.

## 🎯 Requisitos

* Usar `for...of` para imprimir cada item com seu valor total
* Usar `for...in` para listar produtos e preços
* Calcular o valor total do inventário
* Usar `for` clássico para percorrer em ordem inversa
* Encontrar o item mais caro
* Usar `continue` para pular itens com quantidade 0
* Criar um novo array com itens que possuem quantidade maior que 1
