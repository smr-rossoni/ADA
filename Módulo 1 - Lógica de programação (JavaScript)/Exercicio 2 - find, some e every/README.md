# 📊 Exercício 2 — find, some e every

## 📌 Descrição

Utilizar os métodos `find`, `some` e `every` para percorrer arrays sem modificar a memória, aplicando condições e analisando os resultados retornados.

## 🎯 Requisitos

* Usar `find` para encontrar o primeiro elemento que satisfaça uma condição
* Usar `some` para verificar se existe pelo menos um elemento que satisfaça uma condição
* Usar `every` para verificar se todos os elementos satisfazem uma condição
* Exibir os resultados no console
