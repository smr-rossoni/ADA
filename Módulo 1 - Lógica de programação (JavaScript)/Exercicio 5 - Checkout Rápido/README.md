# 📊 Exercício 5 — Checkout Rápido

## 📌 Descrição

Simular um checkout utilizando um objeto `pedido`, aplicando validações e operadores do JavaScript.

## 🎯 Requisitos

* Receber um objeto `pedido` com:

  * `itens`
  * `total`
  * `vip`
  * `cep`
  * `cupom`
* Utilizar:

  * `?.` (optional chaining)
  * `if / else if / else`
  * Operador ternário
  * `??` (nullish coalescing)
  * `switch`
  * Operadores lógicos `&&` e `||`
* Demonstrar casos de **truthy/falsy**
