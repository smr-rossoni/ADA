# 📊 Exercício 1 — Média, Média Ponderada e IMC

## 📌 Descrição

Implementar média simples e média ponderada com pesos variáveis, testar coerções de tipos, formatar a saída (`toFixed`, `Intl.NumberFormat`) e calcular o IMC exibindo um número inteiro.

## 🎯 Requisitos

* Média simples
* Média ponderada (pesos variáveis)
* Teste de coerções
* Formatação de saída
* Cálculo de IMC (inteiro)
